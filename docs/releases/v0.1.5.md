# ProtoLens v0.1.5

## 修复与优化

- 修复更新下载按钮被同源安全策略拦截，改由浏览器原生下载，并提供发版页面入口。旧版本若点击更新仍提示 Failed to fetch，请从本发布页手动下载安装一次。
- 普通点选协议直接加载详情，减少重复排名和整页查询；避免详情切换带动整页单元格更新，行操作改用共享浮层，大数组按可见项读取。
- 打开行操作菜单即暂停列表跟随并取消在途刷新，避免新消息打断操作；后台继续采集，点击“回到最新”恢复。
- 新增行内一键排除、按协议种类批量勾选及跨页选择；合并已有排除条件，失败时保留选择以便重试。
- 清空本次采集消息改为直接入口；详情标题与元信息重新排列，隐藏页面释放实时订阅，恢复时补读状态。
- 新增 macOS / Linux 源码启动入口 `sh ./start-protolens.sh`，补齐分平台启动、证书、代理和路径填写说明。
- “更多”中的“使用说明”改为“SAZ 导入说明”，实时采集继续使用独立的“接入步骤”；删除过期临时文档。

## 平台与路径

- Windows 源码启动：`.\start-protolens.cmd`。
- macOS / Linux 源码启动：`sh ./start-protolens.sh`。
- 目录按工作台所在电脑的本机格式解析，支持 macOS `/Users/...` 及空格、中文目录。页面与 JSON 配置请使用完整路径，不自动展开 `~`、`$HOME` 或 `file://`。
- macOS 发行包仍为 Java 21 启动包，解压后在 ProtoLens 目录执行 `sh ./ProtoLens`；原生工具须匹配本机架构。
- 自动接管系统代理目前仅支持 Windows；macOS / Linux 需手动配置 HTTP / HTTPS 代理并信任公开 CA，退出后手动恢复代理。
- CI 的三平台构建、脚本及路径测试不等同于 macOS / Linux 实机游戏流量采集验收。
