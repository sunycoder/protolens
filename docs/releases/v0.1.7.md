# ProtoLens v0.1.7

本版完善实时阅读、协议查询和操作分析，让列表刷新、固定详情、筛选与保存范围更清楚。

## 实时阅读与交互

- “跟随新消息”表示当前列表状态；“点击消息时”可选择暂停列表，或继续刷新并固定详情。滚动和拖动滚动条不再意外取消跟随。
- 新增通知按当前筛选和保留范围统计，隐藏心跳等条件继续生效；临时查看与长期筛选分开，回到最新保留用户条件。
- 协议关注、固定详情后续消息、证据定位与返回原消息；修复星标撑高消息行的问题。
- 本页显示支持逐条消息、相同内容折叠和同协议归组；归组允许内容不同并提供展开入口，不改变原始消息和统计。
- 新控件统一使用 Element Plus，并修复选择框宽度覆盖导致已选项不可见的问题。

## 协议与操作分析

- 查询字典中的协议和结构定义，并从消息字段跳转源码定义。
- 新增自定义字段列、字段值格式转换、消息及字段批注、字段变化关注。
- 支持时间定位、操作回顾、两次操作对照、异常协议聚合，以及最多 5 个临时分析页签。
- 已确认的同角色记录按目标来源、区服和字典视觉归组，各连接消息仍独立。
- 分析面板按需加载；字段投影仅处理当前页，分析明确扫描、分组及时间线的截断范围。

## 保存与接入

- “保存此刻”“持续保存”明确区分保存当时内容与后续消息；可查看内存和磁盘的保存范围。
- Windows、macOS、Linux 接入指南可切换，使用实际运行地址和公开证书下载入口。
- macOS 系统代理接管与恢复、授权复用，以及既有原生 DMG 打包流程保持兼容。
- 增加前后端能力检查，旧后端缺少接口时提示先保存临时记录并重启，统计失败不再伪装为零新增。

## 使用边界

升级前请保存临时记录并退出旧工作台；重启后刷新页面。批注保存在当前浏览器本机存储，可单独导出；不随抓包快照自动迁移。

折叠和归组仅覆盖当前页；分析结果只表示实际保留范围，不自动推断请求响应或操作因果关系。macOS 应用尚未配置 Apple Developer ID 签名和公证；本版跨平台 CI 打包验收不能代替全部系统的人工实机验收。
