# ProtoLens v0.1.4

本次更新集中改善协议检索、上下文定位与数据阅读体验。

- 搜索结果可跳转到目标消息所在页，自动滚动并整行高亮；支持返回原搜索现场。
- 明确区分消息序号与协议 ID；上下文保留排序，可选择当前连接或全部连接。
- 工作台按实际数据区宽高自动安排详情，支持右侧、底部、浮层及专注列表；记录侧栏、筛选、诊断按需展开。
- 支持配置可见列与恢复默认布局；布局切换保留选中消息及阅读位置。
- 查询成功后同步更新条件、计数与列表；等待、取消或失败时保留原结果，支持重试。
- 详情加载时显示目标消息身份并隐藏旧内容；提供失败重试及空结果恢复入口。
- 支持命中字段摘要、JSON 字段定位和高亮、长值展开与完整值复制。
- 支持固定两条消息对比字段变化；搜索和对比有明确的扫描与展示上限。
- 支持方向键连续阅读和 Esc 收起详情、退出专注；输入框与弹窗不抢快捷键。
- 更新独立仓库启动脚本、操作说明及持续集成测试。

## 下载与运行

- Windows x64：安装程序 `ProtoLens-latest.exe`，或便携包 `ProtoLens-0.1.4-windows-x64.zip`。
- Linux x64：`ProtoLens-0.1.4-linux-x64.tar.gz`。
- macOS：`ProtoLens-0.1.4-macos.tar.gz`；沿用便携启动脚本，系统需已安装 Java 21。

升级前请通过托盘退出正在运行的旧版本，再安装或替换程序目录。保留自己的数据目录。
