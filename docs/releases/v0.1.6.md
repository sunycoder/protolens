# ProtoLens v0.1.6

本版完善抓包分析工作台，并提供 Apple Silicon 与 Intel 两种 macOS 原生 DMG 安装包。

## 分析工作台

- 协议快捷筛选、单条和批量排除使用精确匹配；保留未提交搜索条件，支持撤销并恢复阅读位置。
- 新增协议概览，支持按协议分布缩小范围、多选仅看或排除。
- 采集中可保存独立快照，也可显式开启持续落盘；区分内存保留范围与磁盘保存范围。
- 操作区间可填写背景并保存分析快照；支持一键对比同连接、同方向的上一条同协议消息，以及按业务 ID 对齐数组。
- 刷新恢复上次记录、查询、选中消息与详情标签；支持保存常用筛选和显示列。
- 大 JSON/HEX 在后台格式化，按需展开文本；改进窄窗口侧栏、跟随状态和诊断提示。
- 拆分查询结果与详情状态，增加实时消息索引，将耗时查询计算移出采集锁。

## 下载与安装

- Windows x64：`ProtoLens-latest.exe` 或对应 ZIP。
- macOS Apple Silicon：`ProtoLens-0.1.6-macos-arm64.dmg`。
- macOS Intel：`ProtoLens-0.1.6-macos-x64.dmg`。
- macOS 便携包包含对应架构的完整 `.app`；Linux 提供 x64 tar.gz。

macOS 包内置 Java、Node 和采集器。将应用拖入 Applications 后启动，无需另装运行环境或执行启动命令。实时采集仍需按应用接入步骤信任证书、配置代理。

当前 macOS 应用尚未配置 Apple Developer ID 签名和公证，首次打开可能需要在系统“隐私与安全性”中允许。持续落盘不提供断电级持久化保证；未保存且未开启持续落盘的临时记录退出后仍会丢失。
