# 抓包分析工作区

所有分析保留原消息编号与字典，不修改游戏状态。新功能需要重启新版后端并刷新页面；升级前先保存临时抓包。

| 功能 | 入口与边界 |
| --- | --- |
| 兼容检查 | 启动时核对后端能力；缺少接口时禁用相关分析入口，提示保存并重启。 |
| 临时查看 | 通知和时间定位以临时提示条展示，返回最新保留原筛选及用户后续修改。 |
| 保存操作 | 保存此刻只保存当前保留内容；持续保存追加后续消息，不追补启用前已淘汰内容。 |
| 保留范围 | 页签右侧查看内存范围、上限、磁盘范围、清空及淘汰状态。 |
| 工具栏 | 账号备注归入记录操作，低频分析集中到分析工具，操作期间突出结束入口。 |
| 字段关注 | JSON 标量右键或 ⋯ 添加关注；同连接、同方向、同协议，最多 3 个，本记录有效。 |
| 操作回顾 | 开始标记后执行游戏操作，结束自动查看原区间摘要，支持导出和保存区间。 |
| 账号归组 | 仅对同字典、同目标来源、同区服、同已确认角色的单连接记录视觉归组；消息仍隔离。 |
| 字段列 | JSON 字段操作添加，按字典保存，最多 6 列；缺失为 —，容器显示项数。 |
| 本页显示 | 可选逐条、相同内容折叠或同协议归组。完整解码折叠比较业务正文；部分/失败消息额外核对原始包。同协议归组允许内容不同与协议穿插，按连接、方向、协议及状态隔离，可展开核对原编号；不改变统计或导出。 |
| 时间定位 | 输入 HH:mm:ss 或带毫秒时间，查找当前筛选下最近保留消息及前后 0～60 秒；不推断日期和时区。 |
| 批注 | 消息和字段支持备注、推测、已验证，按记录与原编号绑定，本机浏览器保存，可导出。 |
| 字段格式 | 原值保留，可选十六进制、字节数、秒/毫秒时间戳，日期明确为 UTC；不猜测单位。 |
| 操作对照 | 选两个记录及原编号区间，比较协议/方向次数、字段末次采样及原消息顺序，不自动配对请求响应。 |
| 临时页签 | 最多 5 个，双击重命名，切换恢复筛选、页码、滚动、详情和字段位置；只刷新当前页签，切换记录后重置。 |
| 异常协议 | 按协议、方向与真实解码状态聚合，提供首次/样本入口，不把异常状态改成成功。 |

顶部“跟随新消息”控制当前追新状态；“点击消息时”是点击行为偏好，可选择暂停列表或继续刷新并固定详情。滚动不取消跟随，明确历史导航会暂停。

分析只覆盖保留范围，最多扫描 200000 条并采用 250ms 循环预算；单个大消息的搜索可能超过循环预算，不是硬实时保证。分组最多 1000 组、时间线最多 2000 条，缺失和截断显式提示。字段采样不代表完整服务器状态或因果关系。

字段列偏好保留最近 12 个字典；批注每记录最多 200 条、本机总计最多 2000 条。达到上限或本机存储失败时拒绝保存，不静默删除批注。清理浏览器数据会删除本机批注，抓包快照不自动携带批注。
